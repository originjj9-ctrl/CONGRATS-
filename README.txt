GRADUATION SURPRISE WEBSITE
============================

Main file:
- index.html

Assets:
- assets/images/ contains the five graduation photos
- assets/videos/ contains the supplied graduation video

SPCK EDITOR
-----------
1. Extract this ZIP.
2. Open/import the extracted folder in SPCK.
3. Open index.html.
4. Use SPCK's preview/run option.
5. The website works without a server because all assets use relative paths.

GITHUB PAGES
------------
1. Create a GitHub repository.
2. Upload ALL files and folders inside this project (not the ZIP itself).
3. Make sure index.html is in the repository root.
4. On GitHub go to Settings -> Pages.
5. Choose "Deploy from a branch".
6. Select your main branch and "/ (root)".
7. Save and wait for GitHub Pages to publish.

IMPORTANT:
- Keep the assets folder and its contents in the same structure.
- Do not rename files unless you also update the paths in index.html.
- No external libraries or internet connection are required.
- No background/theme music has been included.
